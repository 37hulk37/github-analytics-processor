## Парсер пре-ридов статей с Хабра согласно запросу

### Описание
Парсер позволяет собрать в json-файлы пре-риды статей согласно указанным поисковым запросам. На каждый запрос будет создан соответствующий json.
Поиск осуществляется по заголовку и первому абацу статьи и подразумевает вхождение каждого слова из запроса либо в заголовок либо в пре-рид статьи. Так, запрос "Go 1.27" отберёт статьи вида: "Вышла новая версия Go - 1.27!".
Парсер написан с поддержкой версии Python 3.9.

### Запуск
В виртуальном окружении установите зависимости:
```
pip install -r requirements.txt 
```
Запуск осуществляется с обязательным указаниием флага -q - его можно указывать несколько раз:
```
python parser.py -q "Go 1.27" -q "<Любой запрос>"
```
В той же директории появятся json-файлы, названные в соответствии с указанными запросами.
