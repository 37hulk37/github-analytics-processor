# Анализ хайпа событий в IT

Командный проект по курсу «Наука о данных» Никифоров.

## Структура репозитория

- `processor/` — Spring сервис, обрабатывающий события GitHub-репозиториев из Kafka и считающий метрики/ML-предсказания (см. `processor/CLAUDE.md`).

Репозиторий общий для всех сервисов проекта; `.gitignore` в корне один на всех, а специфичные для конкретного сервиса файлы (например, `CLAUDE.md`) лежат внутри его папки.
